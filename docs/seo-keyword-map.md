## Rules for future routes

- Create a new indexable route only when it can answer a distinct visitor question with original evidence.
- Keep the page title, H1, opening paragraph, internal-link anchors, and primary intent aligned without repeating an exact phrase unnaturally.
- Do not create thin technology or location pages that restate homepage copy.
- Review Search Console query data before adding capability pages so new routes address demonstrated demand rather than guesses.
